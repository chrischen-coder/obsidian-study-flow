# 可选：网页与 ChatGPT 剪藏

安装官方 [Obsidian Web Clipper](https://obsidian.md/clipper)，在扩展模板设置中导入 `网页记忆.json` 与 `ChatGPT记忆.json`，选择你自己的库名。

1. 在网页选中必要段落，或用扩展高亮器标记内容。
2. 打开扩展，选择模板。
3. 在保存预览中，将两个占位文字改成「一个可回忆的问题」和「自己的答案」，再保存。
4. 卡片写入 `01_记忆卡片`，默认标签为 `#flashcards/通用/概念`。

未选中内容时模板只输出提示，避免整页进入复习。模板不会替你填写答案，也不能阻止在预览中保留占位文字；保存前必须检查。附件图片可能仍是远程链接，长期需要的图建议用核心截图建卡流程保存在本地。

模板目录和标签独立于 `StudyFlow/config.json`，修改配置后也要修改模板的 `path` / 卡组标签。JSON 已通过结构检查；本次发布未在浏览器扩展中完成交互验证，核心截图、复制和 PDF 流程不依赖该扩展。

模板格式参考 [官方模板指南](https://help.obsidian.md/web-clipper/templates)。
