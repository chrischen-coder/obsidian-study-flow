# Study Flow v0.2 原生插件指南

[English](native-guide.en.md) · [项目首页](../README.md) · [旧 QuickAdd 教程](guide.md)

## 安装：不需要 Node 或 QuickAdd

v0.2 是原生桌面插件预览，尚未正式发布或上架社区市场。安装包来自本功能 PR 的 [Actions 构建产物](https://github.com/crown-sports/obsidian-study-flow/actions)。登录 GitHub，打开对应运行，下载任一通过验证的平台 artifact，解压后可见三个 ZIP 和 `SHA256SUMS`。

| 包 | 用途 |
| --- | --- |
| `obsidian-study-flow-plugin-v0.2.0.zip` | 在已有库中安装本项目原生插件 |
| `obsidian-study-flow-example-v0.2.0.zip` | 包含本插件和原创 PDF 的独立练习库 |
| `obsidian-study-flow-starter-v0.2.0.zip` | 保留旧 QuickAdd 宏的示例库，不包含原生插件 |

已有库：解压插件 ZIP，将整个 `study-flow` 文件夹放到库内 `.obsidian/plugins/`，重启 Obsidian，再在设置 → 第三方插件中启用 **Study Flow**。示例库：直接将解压的 `Study-Flow-Example` 文件夹作为新库打开，再启用 Study Flow。建议先在示例库练习。

在社区插件市场安装并启用 **PDF++**、**Spaced Repetition**。工作台提供各自的安装入口，并显示启用状态和版本；安装后返回工作台配置，状态会刷新，也可点击“检查依赖状态”。当前尚未保存的配置保留。Study Flow 不修改第三方插件设置。

## 1. 保存默认配置

点击左侧 🎓 图标，或运行命令 **Study Flow: 打开学习工作台**。可以在命令面板选择 **在标签页打开学习工作台**，获得更大的整理空间。

选择语言、默认分类和默认卡组。展开“目录、分类与卡组”可修改输出位置，或导入 `StudyFlow/config.json` 的旧配置并确认保存。默认目录为 `02_PDF学习/摘录`、`01_记忆卡片` 和 `99_附件`。目录变更只影响新文件。

![真实 Obsidian 上手配置](images/v0.2/01-setup.png)

## 2. 阅读时只收集原文

将带文字层的 PDF 放进当前库。打开 PDF，拖动选中文字，运行 **Study Flow: 保存 PDF 选区**。也可把工作台开在右侧栏，直接点击“保存 PDF 选区”。操作会立即快照当前选区，保存后保留阅读位置，不要求当场写理解。

同一本书、同一页、同一选区与同一原文重复保存会返回已有摘录；原文内容变化时保留新快照。每条摘录都是独立 Markdown，包含 PDF 选区、页码、学习笔记与原文快照。

![真实 PDF 快速摘录](images/v0.2/02-capture.png)

## 3. 用自己的话理解，再制卡

在“摘录收件箱”按资料、分类、状态或文字搜索筛选。点击“写理解”，解释概念、举例或记下疑问。保存理解后，可以为同一摘录建多张卡片。

问题要能独立回答，答案使用自己的理解。一张卡片尽量只测试一个知识点。空问题或空答案不能发布；“保存草稿”将问答放在 frontmatter，正文没有 SR 卡片语法，所以草稿不进入复习。

预览时先看问题，再展开答案。确认卡组后发布，问答正文才生成 SR 可识别的格式。

![真实收件箱制卡与预览](images/v0.2/03-inbox-card.png)

## 4. 进入原生复习，返回原文

“今日复习”提供 SR 原生复习入口，包含到期卡与新卡。显示的数量覆盖 **全部 SR 卡组**，包含其他插件或手工创建的卡片；SR 数据尚未就绪或接口变化时不猜测数量。

先回忆，再显示答案，按实际情况评分。卡片背面包含原文与摘录链接；普通笔记文件也能直接打开这些链接。选区定位不可用时可以按页码返回；PDF 缺失时仍能在摘录中查看原文快照。

![真实 SR 复习、来源和评分](images/v0.2/04-sr-review.png)

修改已复习卡片请从工作台“编辑与预览”进入，问题、答案与卡组可以一起改。文件路径与稳定 ID 保持，已有 SM-2 / FSRS 调度注释按原样保留。修改学习内容后是否需要重新学习由你判断；本项目不重新计算调度。

## 阅读进度、截图和复制

已经保存摘录或手动保存过进度的 PDF 会开始记录页码。页面变化后延迟 1.5 秒保存，切换时刷新；可以随时运行 **保存 PDF 阅读进度**。未开始学习的 PDF 不创建学习文件，读到最后一页也不会自动标记读完，请在工作台确认。

“复制或选中文字变卡片”优先使用笔记编辑器选区，再读取桌面剪贴板。确认输入并保存草稿或发布；取消不写文件。“截图变卡片”需要先把图片放进剪贴板，编辑窗口先显示预览，点击保存时才写 PNG。卡片写入失败会清理本次新建、尚未被卡片引用的图片；已保存草稿引用的附件保留。

## 旧数据：先预览、备份，再升级

工作台识别已有旧学习笔记与卡片，提供原文件入口。点击“升级旧数据”查看书本、摘录、卡片与跳过项目；明确确认“备份并升级”后才写入。

原文件备份到 `StudyFlow/upgrade-backups/`。旧学习笔记保留原内容，旧摘录另外成为新文件并记录来源，旧卡片补充稳定 ID，保留问题、答案和 SR 调度。再次升级不会生成重复对象。

通过命令 **恢复升级备份** 选择一个备份。恢复前会检查全部文件；如果已有新的编辑或复习记录，则停止，避免覆盖你的新数据。中途失败的升级也可以恢复到原内容。备份目录应完整保留。

原宏的 `StudyFlow/scripts/` 路径继续有效：原生插件启用时转接 `api.v1`，题目、答案、分类参数保留；未启用时仍执行旧版 QuickAdd 流程。旧 JSON 继续服务旧流程，导入后原生设置独立保存。

## 手工编辑和常见恢复

- 可修改已有管理区域内的理解、问题、答案；保留 `study_flow_*` 属性和内容边界。不要把整段管理区域删掉。管理区域外的自由笔记会保留。
- 编辑窗口与文件同时修改时，窗口保留你的输入并展示最新内容供比较。SR 只更新调度时自动合并调度；内容冲突需你选择载入新版或明确保存自己的输入。
- PDF 重命名会更新来源；学习笔记、摘录移动后按稳定 ID 和引用修复关联。不要复制一个文件后继续沿用相同 ID 来创建第二个学习对象。
- PDF 删除后可打开摘录快照。工作台会显示“重新关联 PDF”，选择库内资料并确认即可修复来源；也可编辑书本笔记的 `PDF文件` 链接。原摘录快照始终保留。
- 已保存但书架刷新失败：文件已经落盘，点击“刷新书架”重试。文件格式被手工破坏时，工作台提示问题路径，可打开原文件修复并重建索引。
- PDF++ / SR 缺失或内部接口不兼容时，数据继续保留；通过配置页恢复依赖。SR 未启用时仍可保存草稿。

## 兼容范围

桌面本地处理，无网络请求、OCR、AI 服务或自动答案。扫描 PDF 需要先有文字层。手机可同步 Markdown 和附件，用手机 SR 复习；本版本不提供移动端采集界面。

已实际验收：macOS、Obsidian 1.13.7、PDF++ 0.40.31、SR 1.15.4。Windows / Linux 的构建和文件测试由 CI 执行，应用操作尚未验收。详见 [验证记录](validation-v0.2.md)。

SR 默认语法、普通正向多行卡、自定义多行问答分隔符和文件夹卡组已覆盖。自定义行内分隔符、卡片结束标记、自定义挖空模式、独立代码围栏与非 NOTES 调度存储尚未支持发布，界面会说明原因并允许存草稿；不会自动改第三方配置。

开发者从源码构建：Node 20+，运行 `npm ci`、`npm run check`、`npm test`、`npm run package`。产物在 `dist/`，安装无需携带 `node_modules`。架构和对外接口见 [architecture.md](architecture.md)。
