# Study Flow by crown · v0.2

先保存原文，稍后理解，再把值得记住的内容做成卡片。
Capture first, understand later, then make cards for what matters.

1. 在 Obsidian 中打开这个文件夹作为新笔记库，启用 **Study Flow**。
   Open this folder as a new Obsidian vault and enable **Study Flow**.
2. 点击左侧 🎓 学习工作台。按配置页入口从社区安装并启用 **PDF++** 和 **Spaced Repetition**，然后保存默认配置。
   Open the 🎓 workbench. Install and enable **PDF++** and **Spaced Repetition** from the community browser, then save the defaults.
3. 打开 [[03_PDF/主动回忆示例.pdf]]，选中前两行。运行命令 **Study Flow: 保存 PDF 选区**；也可以打开侧栏工作台后点保存选区。
   Open the original PDF, select the first two lines, and run **Study Flow: Capture PDF selection**, or use the workbench in the sidebar.
4. 在 **摘录收件箱** 写自己的理解，再建卡。草稿不会进入复习；填写问题与答案，预览后发布。
   Write your understanding in the **Inbox**, make a card, preview and publish. Drafts stay outside review.
5. 在 **今日复习** 打开 SR 原生复习。先回忆，再显示答案，评分；答案背面可以返回原文。
   Open native SR from **Review**. Recall, reveal, rate and return to the source from the card back.

已开始学习的 PDF 会自动保存页码；读完状态由你标记。文件都保存在本地 Markdown，可以手工编辑、同步和导出。
Reading progress is saved for PDFs you have started. Mark books finished yourself. Your Markdown files remain editable, syncable and exportable.

原生插件不需要 QuickAdd 或 Node。旧 QuickAdd 示例另有 starter 包。本示例仅包含本项目插件与原创 PDF，第三方插件请从社区安装。
The native plugin needs neither QuickAdd nor Node. The separate starter package keeps legacy QuickAdd workflows. This example bundles only our plugin and original PDF; install third-party plugins from the community browser.
