## 已解决的集成问题

- SR 独立 HTML 注释会跳过下一行，最初的问答边界导致卡片未被识别。改为连续问答和嵌入来源标记，固定原生解析器回归测试与真实复习均已通过。
- SR `dueRepItems` 也包含未来卡片。统计适配器验证 `isDue`，不把未来卡片当作已到期；未知结构或同步中不展示数量。
- 同一 PDF 的非活动标签页可覆盖进度。现在只观察当前 reader，并在切换时刷新。
- 截图 PNG 转成精确的 ArrayBuffer，写入延迟到卡片保存；取消与失败路径由测试和真实取消验证。
- 配置页保留未保存的输入时，依赖安装状态曾不刷新。现在返回窗口时只刷新依赖区域，并提供手动检查按钮，保留配置草稿。
