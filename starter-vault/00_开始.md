# Obsidian Study Flow

把值得记住的内容，变成能检验自己的问题。

## 先完成安装

在「设置 → 第三方插件 → 浏览」分别安装并启用 **QuickAdd、PDF++、Spaced Repetition**。全部装好后重新启动 Obsidian。配置和脚本已在这个示例库中准备好。

## 体验第一张卡片

1. 复制一句问题，例如「主动回忆和重读有什么区别？」。
2. 按 `Cmd+P`（Windows / Linux 为 `Ctrl+P`），运行「QuickAdd: 复制变错题卡」。
3. 选分类，确认题目，填写答案。新卡片保存在 `01_记忆卡片`。
4. 再打开命令面板，搜索 `Spaced Repetition`，运行复习卡片的命令。先回答，再显示答案，诚实评分。

[截图变错题卡](obsidian://quickadd?choice=截图变错题卡) · [复制变错题卡](obsidian://quickadd?choice=复制变错题卡) · [文字变错题卡](obsidian://quickadd?choice=文字变错题卡)

截图要放入剪贴板，只有保存成文件还不够。macOS：`Ctrl+Cmd+Shift+4`；Windows：`Win+Shift+S`；Linux：使用能复制图像到剪贴板的截图工具。

## PDF → 理解 → 记忆卡片

1. 打开 [[03_PDF/主动回忆示例.pdf|原创示例 PDF]]，拖动选中文字。
2. 点文件列表上方「保存划线」，填写自己的小结。
3. 若想进入间隔复习，勾选「同时生成记忆卡片」，写一个可回忆的问题。
4. 点「保存原文和小结」，再选卡组与 PDF 分类（首次）。保存后继续留在 PDF。
5. 暂停前运行「QuickAdd: 保存PDF阅读进度」。从 [[02_PDF学习/PDF书架|PDF 书架]] 的「继续阅读」链接回来。

[新建 PDF 学习卡](obsidian://quickadd?choice=新建PDF学习卡) · [保存 PDF 阅读进度](obsidian://quickadd?choice=保存PDF阅读进度) · [打开 PDF 摘录](obsidian://quickadd?choice=背诵PDF摘录)

「背诵摘录」打开学习笔记，供你遮住原文练习复述；勾选生成的记忆卡片由 Spaced Repetition 管理到期复习。PDF 学习卡负责摘录、理解和进度，本身不会自动变成整篇复习卡。

接入已有库的用户可使用自己的 PDF；若要用上面的示例，请从源码或示例 ZIP 复制 `03_PDF/主动回忆示例.pdf` 到库内。

## 自定义与帮助

改分类、卡组和输出目录：编辑 `StudyFlow/config.json`。脚本目录 `StudyFlow/scripts` 请保留原名。输出目录会自动建立。

支持桌面版建卡；手机可使用 Spaced Repetition 复习同步后的 Markdown 卡片。扫描 PDF 需先有 OCR 文字层。本项目不会自动识字、生成答案或修改 PDF 文件。

项目与完整图文指南：[GitHub](https://github.com/chrischen-coder/obsidian-study-flow)。
